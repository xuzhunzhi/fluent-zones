# 路线图

> Fluent 风格的 Windows 窗口分区工具。核心是"按声明的尺寸智能排布 + 可拖拽分区"，
> 长期目标是取代任务栏里"窗口切换"那部分功能。

## 版本规划

| 版本 | 主题 | 状态 |
|---|---|---|
| v0.1.0 | 一次性布局：5 种布局 + 还原、按最小尺寸分配、提权窗口、DWM 可见边框对齐 | 已发布 |
| v0.2 | 分区工作区：可拖槽位、新窗踢旧窗、主槽队列、层叠统一尺寸 | 开发中 |
| v0.3 | 工作区条：每屏一条，显示槽位与窗口，点击聚焦 / 拖动换槽 | 规划 |
| v0.4 | 取代任务栏的窗口切换：`Ctrl+Alt+Tab` 在工作区条上循环，隐藏系统任务栏也能完整切换 | 规划 |

## v0.2 范围（分区工作区）

**做**

- `Ctrl+Alt+Z` 进入 / 退出当前显示器的工作区；
- 进入时按偏好设置决定槽位策略：动态分配（默认）/ 固定 N 格 / 每次询问；
- 层叠以外的布局（左右并排、上下堆叠、网格、主窗在左）映射成固定槽位，槽位边界可拖，两侧窗口实时同步；
- 工作区开启期间，新出现的窗口自动入槽，把该槽位里 Z 序最底（最久未激活）的窗口踢出；被踢出的窗口层叠滚到角落；
- 主槽（主窗在左）与层叠模式都有窗口队列，`Ctrl+Alt+Tab` 轮换（反向 `Ctrl+Alt+Shift+Tab`）；
- 层叠模式下所有窗口统一尺寸，可整体调整。

**不做（留到 v0.3+）**

- 工作区条 UI；
- 隐藏系统任务栏；
- 跨显示器的工作区迁移；
- 应用启动器 / 托盘 / 通知。

## v0.3 范围（工作区条）

- 每台显示器一条（默认贴工作区顶部，可配置），显示：槽位顺序、每个槽位当前窗口的图标 + 标题、队列里还有几个窗口；
- 点击槽位 = 聚焦该窗口；拖动槽位 = 交换窗口；双击 = 最大化/还原；
- 前台窗口变化时高亮对应槽位（`EVENT_SYSTEM_FOREGROUND`）；
- 队列轮换的视觉反馈（谁被抽出、滚到最前）。

## v0.4 范围（取代任务栏的窗口切换）

- 工作区条常驻（可隐藏系统任务栏），鼠标和 `Ctrl+Alt+Tab` 都能切换；
- 窗口操作：置顶、关闭、移出工作区、送入另一个槽位的队列；
- 多显示器各自一条，互不干扰。

**明确不做**：开始菜单、系统托盘、通知中心、应用启动器。这些不属于"窗口管理"。

## 非目标与约束

- 不接管系统级窗口行为（不 hook 其他进程的 `WM_SIZING`）；
- 不修改系统任务栏本身，只提供替代入口；
- 提权窗口（如 Windhawk）需要本工具以管理员身份运行才能操作，沿用现有 UIPI 处理；
- 所有坐标使用物理像素，对齐以 DWM 可见边框为准。
