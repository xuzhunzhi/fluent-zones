# 布局卡片设置

## 交互

- **卡片主体单击**：立即按该布局排布（保持现状，不进设置）；
- **卡片右上角齿轮**：打开该布局的设置弹窗；弹窗内的操作不触发排布（齿轮单独吃掉点击事件）；
- 弹窗底部：`恢复默认` / `取消` / `保存`；保存即写入 `settings.json`，下次排布生效；
- 齿轮平时淡显，鼠标悬停卡片时变明显。

## 参数

| 布局 | 参数 | 默认 |
|---|---|---|
| 层叠（Cascade） | 最多窗口数 | 8 |
| | 错开步长 | 30px |
| | 窗口占工作区比例 | 75% |
| 左右并排（Columns） | 最多列数 | 0 = 不限（自动分行） |
| | 窗口间距 | 沿用全局 |
| 上下堆叠（Rows） | 列数 | 2（固定） |
| | 左列宽度比例 | 55% |
| | 每列最多窗口数 | 0 = 不限 |
| 网格（Grid） | 最多窗口数 | 4（范围 2–6，已实现） |
| | 主窗占比 | 62% × 62%（暂固定，未做成设置） |
| | 主窗位置 | 左上（暂固定，未做成设置） |
| 主窗在左（MainLeft） | 最多窗口数 | 3 |
| | 主窗宽度比例 | 55% |

## 超限窗口

超过"最多窗口数"的窗口**直接最小化**（按 Z 序，最久没用的先下去），状态栏提示「已排列 N 个窗口，最小化 M 个最久未使用的窗口」。
`Ctrl+Alt+0` 还原时会把它们一起放回去。

## 取哪 N 个

前台窗口优先，其余按 Z 序从前往后取。
与"主窗在左"选择主窗的逻辑一致。

## 持久化

```json
{
  "LayoutLimits": { "Grid": 4 }
}
```

键是 `LayoutKind` 的名字；缺失或 0 表示不限制。目前只有 `Grid` 会读这个值，其余布局的参数（层叠 8 / 主窗在左 3 / 列数 / 步长 / 比例）还没实现。

## 验收

现状（只做了网格）：

1. 单击卡片仍然立即排布，不弹窗；
2. 网格齿轮可点，其余四张卡片的齿轮置灰；
3. 网格设成 4 后，7 个窗口只排前 4 个，其余 3 个被最小化，状态栏有提示；
4. 保存后重启程序设置仍在；「恢复默认」能还原成 4；
5. 待做：层叠 / 主窗在左 / 并排 / 堆叠 的参数。

## 与其他布局的关系

- 设置只影响该布局的"一次性排布"；
- 分区工作区（v0.2）使用独立参数（见 `docs/ZONES.md`），不读取这里的上限。
