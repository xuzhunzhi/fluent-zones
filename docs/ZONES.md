# 分区工作区（Zones）

本文定义 v0.2 的完整行为与验收标准。实现以本文为准，代码在 `src/FluentZones.Core/Zones/`。

## 1. 概念

| 名词 | 含义 |
|---|---|
| 工作区（workspace） | 某台显示器上的一套槽位集合，同一时刻最多一个 |
| 槽位（slot） | 工作区里的一块区域，同一时刻只显示一个窗口 |
| 队列（queue） | 每个槽位里等待上屏的窗口，先进先出 |
| 踢出（evict） | 新窗口入槽时，把该槽位最久未激活的窗口挤出工作区 |
| 主槽（main slot） | "主窗在左"布局中占左半边的槽位 |

## 2. 布局 → 槽位

| 布局 | 槽位 |
|---|---|
| 左右并排（Columns） | n 个并排槽位 |
| 上下堆叠（Rows） | n 个纵向槽位 |
| 网格（Grid） | ⌈√n⌉ 列 × 对应行 |
| 主窗在左（MainLeft） | 1 个主槽（左，默认 55%）+ n-1 个右侧纵向槽位 |
| 层叠（Cascade） | n 个等高槽位，全部叠放在同一区域，按队列决定前后 |
| 还原（Restore） | 不进入工作区 |

槽位数量在进入工作区时按当前窗口数确定，切换布局时按新布局重建。
槽位边界比例用一棵切分树保存（`ZoneNode`），拖拽只改比例。

## 3. 进入与退出

**进入**：`Ctrl+Alt+Z`

1. 取当前显示器上、Z 序从前往后的可见窗口；
2. 按当前选择的布局建槽位（默认：≤3 个用左右并排，4 个以上用网格）；
3. 按顺序把窗口放进槽位；
4. 快照所有窗口的位置（`Ctrl+Alt+0` 可整体还原）；
5. 显示分隔线覆盖层。

**退出**：再按一次 `Ctrl+Alt+Z`，或 `Ctrl+Alt+0`（后者同时还原位置）。
退出时隐藏覆盖层，窗口保持当前槽位尺寸。

**切换布局**：工作区内按布局热键（`Ctrl+Alt+1..5`），按新布局重建槽位，窗口顺序不变。

## 4. 窗口归属

### 新窗口入槽

工作区开着时，`EVENT_OBJECT_SHOW` 触发：

1. 忽略工具窗、无标题、过小、其它虚拟桌面、本程序、提权且无权限的窗口；
2. 选一个目标槽位（默认：当前主槽优先，其余情况选"最近最少使用"的槽位）；
3. 把该槽位当前窗口的**最久未激活者**（Z 序最底）踢出：滚到屏幕角落层叠排布（统一尺寸、错开 28px、露出标题栏）；
4. 新窗口占据该槽位，并重排该布局。

> 被踢出的窗口不最小化、不关闭；它们只是离开工作区，仍可被正常激活。

### 关闭 / 最小化

- 窗口关闭：槽位从队列里取下一个补位；队列空则该槽位暂时留空（不重排其它槽位）。
- 窗口最小化：视为离开槽位，同"关闭"处理；恢复时按新窗口规则重新入槽。
- 窗口被手动拖出槽位：不阻止；下一次重排时按当前矩形重新归属（不会强行拉回）。

## 5. 队列与轮换

- 每个槽位维护队列，队首是当前上屏窗口；
- 主槽队列：`Ctrl+Alt+Tab` 把队首移到队尾、下一个上屏（反向 `Ctrl+Alt+Shift+Tab`）；
- 层叠模式：同上，轮换即把下一个窗口抽出并滚到最前（Z 序置顶），尺寸不变；
- `Ctrl+Alt+Tab` 若被系统或其它程序占用，自动回退到 `Ctrl+Alt+Shift+Tab`，并在状态栏说明；两者都可改键。

## 6. 拖拽分隔线

- 覆盖层：置顶、不激活、`WS_EX_LAYERED` 的分层窗口，覆盖工作区；
- 分隔线：2px 实线（强调色），命中区 ±5px；非分隔线区域 `HTTRANSPARENT`，鼠标完全穿透；
- 悬停光标：竖线 `IDC_SIZEWE`，横线 `IDC_SIZENS`；
- 拖动：实时改对应切分节点的比例，两侧窗口同步 `SetWindowPos`（带 DWM 可见边框补偿）；
- 钳制：任一侧不得小于其子树的最小尺寸（取窗口声明的 `WM_GETMINMAXINFO` 与 120×90 下限的较大值）；
- 双击分隔线：该节点恢复均分；
- 坐标：鼠标消息是客户区坐标，槽位矩形是屏幕坐标，命中与绘制都必须做一次换算。

## 7. 层叠模式

- 所有窗口同尺寸（默认工作区的 75%），错开 28px，Z 序按队列从前到后；
- "统一尺寸"提供一个整体控制（工作区内的尺寸滑块或热键），调整时所有窗口同步缩放；
- 队列轮换把下一个窗口滚到最前，尺寸与偏移不变。

## 8. 状态与日志

- 状态栏显示：当前布局、槽位数、各槽位窗口数、轮换/踢出事件；
- `%LOCALAPPDATA%\FluentZones\layout.log` 记录：进入/退出、布局变更、槽位分配、踢出、轮换、每次 `SetWindowPos` 的请求值与实际值；
- 覆盖层与槽位状态的变更都写入日志，便于排查"某个窗口没动"。

## 9. 已知风险

| 风险 | 处理 |
|---|---|
| 提权窗口（UIPI） | 识别后排除，提示以管理员身份重启（已有机制） |
| 窗口自绘边框 | 按 DWM `EXTENDED_FRAME_BOUNDS` 对齐（已有机制） |
| 窗口声明的最小尺寸过大 | 拖拽钳制；放不下时提示缩小/移出 |
| `WinEventHook` 事件风暴 | 200ms 防抖，只处理本工作区显示器上的顶层窗口 |
| 高 DPI、多显示器 | 全部使用物理像素；每显示器独立工作区 |
| 应用自身微调窗口 | 排完 600ms 校验一次并扶正（已有机制） |

## 10. 验收清单

1. 5 种布局进入工作区后，分隔线位置与窗口可见边界一致；
2. 拖竖线/横线，两侧窗口同步变化，无重叠、无越界；
3. 拖到最小尺寸时停住，光标仍可继续移动；
4. 新开一个窗口 → 目标槽位最久未激活的窗口被层叠到角落，新窗口入槽；
5. 关闭窗口 → 队列下一个补位；队列空 → 槽位留空，其它槽位不动；
6. `Ctrl+Alt+Tab` 主槽轮换正确，反向热键方向正确；
7. 层叠模式轮换后前窗变化、尺寸与偏移不变；
8. 调整统一尺寸，所有层叠窗口同步缩放；
9. `Ctrl+Alt+0` 能还原到进入工作区前的位置；
10. 日志能完整还原一次"入槽 → 踢出 → 轮换"的过程。
