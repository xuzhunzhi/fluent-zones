# 分区工作区（Zones）

本文定义 v0.2 的完整行为与验收标准。实现以本文为准，代码在 `src/FluentZones.Core/Zones/`。

## 1. 概念

| 名词 | 含义 |
|---|---|
| 工作区（workspace） | 某台显示器上的一套槽位集合，同一时刻最多一个 |
| 槽位（slot） | 工作区里的一块区域，同一时刻只显示一个窗口 |
| 队列（queue） | 每个槽位里等待上屏的窗口，先进先出 |
| 踢出（evict） | 把某槽位最久未激活的窗口挤出工作区，层叠到屏幕角落 |
| 主槽（main slot） | "主窗在左"布局中占左半边的槽位 |

## 2. 布局 → 槽位

| 布局 | 槽位 |
|---|---|
| 左右并排（Columns） | 按每行列数（3 / 4）自动换行；槽位宽度按舒适宽度分配，再按各窗口最小宽拟合修正 |
| 上下堆叠（Rows） | 单列纵向堆叠；槽位高度均分，再按各窗口最小高度拟合修正 |
| 网格（Grid） | 智能马赛克：1 个主窗 + 其余小窗环绕；默认 4 个，上限可配；实际参与数 = min(上限, 能装下的数量) |
| 主窗在左（MainLeft） | 左侧固定主槽（默认 55%）+ 右侧纵向窗口带；v0.2 是 n-1 个纵向槽位，v0.5 起右侧改为无限循环滚动 |
| 层叠（Cascade） | n 个等高槽位，全部叠在同一区域，按队列决定前后 |

槽位边界比例用切分树保存（`ZoneNode`），拖拽只改比例。

## 3. 进入与退出

**进入**：先打开「分区模式」开关（表示启用这些布局的工作区能力，打开时不动窗口），再选一个布局（卡片或 `Ctrl+Alt+1..5`）；也可以直接按 `Ctrl+Alt+Z`（按窗口数自动选并排/网格，层叠除外）。

1. 读取偏好设置「槽位策略」（未设置时按默认「动态分配」；v0.3 起首次使用的引导页会询问）：

   | 取值 | 行为 |
   |---|---|
   | **动态分配**（默认） | 槽位数跟随窗口数；新窗口先尝试扩容排下，装不下才踢出，仍装不下再弹窗 |
   | **固定 N 格** | 槽位数固定为进入时的窗口数；新窗口直接踢出该槽最久未激活的，布局比例不变 |
   | **每次询问** | 进入时弹一个小对话框选本次策略，勾选「记住」会写回偏好 |

2. 取当前显示器上、Z 序从前往后的可见窗口；
3. 按当前布局建槽位（默认：≤3 个用左右并排，4 个以上用网格）；
4. 校验最小尺寸：网格只有换主窗才排得下时先弹窗请求许可（拒绝按放不下处理）；Fit 后仍不满足最小尺寸则**进入失败**——状态栏说明原因，不应用布局（保持原布局 / 不进入）；
5. 校验通过后才快照所有窗口位置（`Ctrl+Alt+0` 可整体还原；进入失败不会污染快照）；
6. 显示分隔线覆盖层。

**退出**：再按一次 `Ctrl+Alt+Z`，或关闭开关（退出工作区，窗口保持当前尺寸）；`Ctrl+Alt+0` 退出并还原到进入前的位置，**开关保持开启**，下次选布局再次进入。

**切换布局**：工作区内按布局热键（`Ctrl+Alt+1..5`），按新布局重建槽位；`动态` 档下槽数 = 当前窗口数，`固定` 档下槽数不变、多出的窗口进队列。

## 4. 窗口归属

### 4.1 动态分配（默认）

新窗口出现（`EVENT_OBJECT_SHOW`）：

1. 候选 = 现有窗口 + 新窗口，按当前布局重新分槽（槽数 = 窗口数）；
2. **装得下**（每个窗口 ≥ 声明的最小尺寸与舒适下限）→ 直接排：
   - 新窗口从**当前最大的槽位**切一块出来（尺寸差 10% 以内时切最久未激活的那个），其余边界尽量保留；
   - 用户拖拽过的比例继续有效。
3. **网格且只有换主窗才装得下** → 弹窗请求许可（允许换主窗 / 不允许）；拒绝按装不下处理，不静默换；
4. **装不下** → 踢出最久未激活的窗口（层叠到角落，并进入该槽队列尾），再试一次；
5. **仍装不下** → 弹窗：最小化 N 个 / 改用层叠 / 取消。

关闭窗口：槽位自动重排（其它格子等比放大），不触发踢出。
最小化窗口：视为离开槽位，同关闭；恢复时按新窗口规则重新入槽。

### 4.2 固定 N 格（进入时选择）

- 槽位数在进入时固定，布局比例由用户拖拽决定，之后不再自动变化；
- 新窗口：有空槽先填空槽；没有则踢出该槽最久未激活的（层叠到角落 + 入队），新窗口上槽；
- 关闭/最小化：队列补位；队列空则该槽位留空，其它槽位不动；
- 手动增/减槽位由工作区条提供（v0.3）。

### 4.3 被踢出的窗口

层叠排布在屏幕右下角：统一尺寸（工作区的 40%）、错开 28px、露出标题栏、不最小化；
同时进入被踢槽位的队尾，可以通过队列轮换回到工作区。

### 4.4 槽位交换

- 工作区内按住窗口拖到另一个槽位，松手即互换（队列位置互换）；
- 拖到空白或工作区外：不交换，窗口按当前矩形归属（下次重排生效）；
- 层叠模式不适用（用队列轮换）；
- 交换不改变槽位比例。

## 5. 队列与轮换

- 队列轮换**仅在工作区开启时可用**；未进入工作区按 \Ctrl+Alt+Tab\ 只提示先进入；\n- 每个槽位维护队列，队首是当前上屏窗口；
- 主槽队列：`Ctrl+Alt+Tab` 把队首移到队尾、下一个上屏（反向 `Ctrl+Alt+Shift+Tab`）；
- 层叠模式：同上，轮换即把下一个窗口抽出并滚到最前（Z 序置顶），尺寸不变；
- `Ctrl+Alt+Tab` 若被系统或其它程序占用，自动回退到 `Ctrl+Alt+Shift+Tab`，并在状态栏说明；两者都可改键。
- 可选：工作区内接管 `Alt+Tab`（低级键盘钩子，进入时挂、退出时卸），循环槽位；`Win+Tab` 留到 v0.4 的自绘总览。详见 [DESKTOPS.md](DESKTOPS.md)。

## 6. 拖拽分隔线

- 覆盖层：置顶、不激活、`WS_EX_LAYERED` 的分层窗口，覆盖工作区；
- 分隔线：2px 实线（强调色），命中区 ±5px；非分隔线区域 `HTTRANSPARENT`，鼠标完全穿透；
- 悬停光标：竖线 `IDC_SIZEWE`，横线 `IDC_SIZENS`；
- 拖动：实时改对应切分节点的比例，两侧窗口同步 `SetWindowPos`（带 DWM 可见边框补偿）；
- 钳制：任一侧不得小于其子树的最小尺寸（`WM_GETMINMAXINFO` 与 120×90 下限的较大值）；
- 双击分隔线：该节点恢复均分；
- 坐标：鼠标消息是客户区坐标，槽位矩形是屏幕坐标，命中与绘制都必须做一次换算。

## 7. 层叠模式

- 所有窗口同尺寸（默认为工作区的 75%），错开 28px，Z 序按队列从前到后；
- "统一尺寸"提供整体控制（工作区内滑块），调整时所有层叠窗口同步缩放；
- 队列轮换把下一个窗口滚到最前，尺寸与偏移不变；\n- **点击任意窗口 = 直接抽到最前**（等价于把它移到队首），其余窗口顺序不变。

## 8. 状态与日志

- 状态栏显示：本次策略、当前布局、槽位数、各槽位窗口数、轮换/踢出事件；
- `%LOCALAPPDATA%\FluentZones\layout.log` 记录：进入/退出、策略选择、布局变更、槽位分配、踢出、轮换、每次 `SetWindowPos` 的请求值与实际值。

## 9. 已知风险

| 风险 | 处理 |
|---|---|
| 提权窗口（UIPI） | 识别后排除，提示以管理员身份重启（已有机制） |
| 窗口自绘边框 | 按 DWM `EXTENDED_FRAME_BOUNDS` 对齐（已有机制） |
| 窗口声明的最小尺寸过大 | 拖拽钳制；动态档下先踢出，仍不行再弹窗 |
| `WinEventHook` 事件风暴 | 200ms 防抖，只处理工作区所在显示器上的顶层窗口 |
| 高 DPI、多显示器 | 全部使用物理像素；每显示器独立工作区 |
| 应用自身微调窗口 | 排完 600ms 校验一次并扶正（已有机制） |

## 10. 验收清单

**通用**

1. 5 种布局进入工作区后，分隔线位置与窗口可见边界一致；
2. 拖竖线/横线，两侧窗口同步变化，无重叠、无越界；
3. 拖到最小尺寸时停住，光标仍可继续移动；
4. `Ctrl+Alt+0` 能还原到进入工作区前的位置；
5. 日志能完整还原一次"入槽 → 踢出 → 轮换"的过程。

**动态分配**

6. 开一个新窗口 → 布局自动多一格并装下，无窗口被踢出，原有比例基本保留；
7. 窗口多到装不下 → 最久未激活的被层叠到角落，其余重排成功；
8. 偏好设为「固定」后进入不再询问；设为「每次询问」时进入弹一次对话框，勾选「记住」会写回偏好。

**固定 N 格**

9. 开第 N+1 个窗口 → 最久未激活的被层叠到角落，槽位数与比例不变；
10. 关闭一个窗口 → 队列补位；队列空则槽位留空，其它槽位不动。

**队列与层叠**

11. `Ctrl+Alt+Tab` 主槽轮换正确，反向热键方向正确；
12. 层叠模式轮换后前窗变化、尺寸与偏移不变；
13. 调整统一尺寸，所有层叠窗口同步缩放；\n14. 工作区内把窗口 A 拖到窗口 B 的槽位，两者互换，槽位比例不变；\n15. 未进入工作区时按 \Ctrl+Alt+Tab\ 只提示，不触发轮换。
