# 智能网格（Grid）

> 目标：不是等分格子，而是"一个主窗口 + 若干小窗口环绕"的马赛克式排布，按格数自动选构图。

## 构图规则

**主窗口**（默认前台窗口）默认占左上角；比例由构图决定（5/6 窗约 62% × 62%），实际会按各窗口最小尺寸拟合微调。3 / 4 窗分别用「左日右口」「左右两个日」，5 / 6 窗用「主窗 + 右侧列 + 底部行」的马赛克。

**5/6 窗的右侧列和底部行各自切，两条分割线不必等高**——所以看起来可以是两个"日"字，左列和右列的横线错开。

### 格数与构图

| 格数 | 构图 | 1920×1080 工作区、间距 6、四边内缩 4px 的参考尺寸（无最小尺寸约束） |
|---|---|---|
| 2 | 竖着一刀，左右 62% / 38%，两块都是全高 | `1182×1072` + `724×1072` |

## 格数上限

- 设置项「最多窗口数」默认 **4**，范围 **2–6**；
- 窗口比格子多时，**多出来的窗口直接最小化**（按 Z 序、最久没用的先下去），状态栏写「最小化 N 个最久未使用的窗口」；
- 窗口比格子少时按实际数量取构图（设 6 格但只有 3 个窗口 → 用 3 格那张图），不留空格子；
- 最小尺寸装不下时：3–6 窗会穷举可行的格子分配；如果只有“换主窗”才排得下，会先弹窗请求许可（允许换主窗 / 不允许），拒绝就按放不下处理（少排 / 最小化 / 提示），**不静默换主窗**。所有分配都放不下才弹「最小化 N 个并排列 / 改用层叠 / 取消」。其它布局（左右并排 / 上下堆叠 / 主窗在左）仍是按 Z 序少排几个、放不下的窗口保持原位。

## 主窗位置

主窗默认左上角、优先用前台窗口；3–6 窗穷举时若只有换主窗才排得下，会先弹窗请求许可（拒绝则不换，主窗位置仍固定左上角）。右上 / 左下 / 右下属于设置项，未实现。

## 与其它组件的关系

- **一次性布局**：按上述构图直接排布，受"最多窗口数"限制；
- **分区工作区**：网格槽位就是马赛克的各个叶子，可拖拽调整主窗占比与右侧/底部边界；
- **滚动工作区（v0.5）**：网格不参与滚动，仍是一屏构图。

## 算法

```
Arrange(windows, area):
  n = min(格数上限, windows.Count)        # 超出的先最小化
  if n == 1: 铺满
  if n == 2: 竖切 ratio = 0.62
  if n == 3: 左日右口（左列 0.62 宽、上下均分，右侧一列通高）
  if n == 4: 左右两个日（左列 0.62 宽、上格约 0.62 高；右列上下均分）
  if n in {5, 6}:
    r = (n - 1) / 2                        # 右侧列的块数（向下取整）
    top    = 横切(主窗, 右侧列(r 块), ratio = 0.62)
    bottom = 底部行((n - 1) - r 块；2 块竖切 0.62，3 块均分)
    root   = 竖切(top, bottom, ratio = 0.62)

  对 3–6 窗：把窗口排列依次代入 Arrange + FitToMinimumSizes，
            选第一个“每格都 ≥ 声明最小尺寸”的排列；
            全部不可行时按自然顺序铺形状，由调用方判定放不下
```

`r` / `b` 下表只适用于 5 / 6 窗，除主窗外先对半分给右侧列和底部行，多出来的那块给底部：

| n | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|
| 右侧列 r | 0（竖切特例） | 1 | 1 | 2 | 2 |
| 底部行 b | — | 1 | 2 | 2 | 3 |

## 验收

1. 4 个窗口：左右两个日——左列 62% 宽（上格约 62% 高）、右列 38% 宽上下平分，互不重叠；
2. 3 个窗口：左日右口——左列 62% 宽上下两格，右侧一列通高；
3. 2 个窗口：竖着一刀，左右 62% / 38%，两块都是全高；
4. 5 / 6 个窗口：主窗 + 右侧 2 块 + 底部 2 / 3 块；右侧列的横线和主窗下沿**不等高**；
5. 7 个窗口、格数上限 4 → 只排前 4 个，其余 3 个被最小化，状态栏说明；
6. 3 个窗口、格数上限 6 → 按 3 格排，不留空格子；
7. 3–6 个窗口：穷举可行分配；只有“换主窗”才排得下时先弹窗请求许可——允许才换，拒绝则不换并走放不下兜底；
8. 自然主窗（前台窗口）排得下时直接排，不弹换主窗对话框；所有分配都放不下才提示最小化 / 改用层叠。
