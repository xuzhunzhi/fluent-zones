# 工作区即桌面（替代 Alt+Tab / 任务视图 / 虚拟桌面）

> 状态：构想（v0.4 起）。本文只定义方向与约束，不承诺具体版本内的完成度。

## 分三级

| 级别 | 内容 | 风险 |
|---|---|---|
| L1 | 工作区内接管 **Alt+Tab**：循环槽位、Shift+Alt+Tab 反向 | 低（可选开关，退出工作区即卸钩子） |
| L2 | 接管 **Win+Tab** 打开自绘"工作区总览"，替代任务视图 | 中（需要缩略图与切换动画） |
| L3 | **虚拟桌面替代**：一个工作区 = 一个桌面，非当前桌面的窗口整体隐藏 | 高（隐藏/恢复窗口的兼容性与崩溃恢复） |

## L3 模型

```
Desktop
  ├─ 名称
  ├─ Workspace[]（每台显示器一个：布局 + 槽位 + 比例）
  ├─ 窗口集合（按槽位 + 队列）
  └─ 缩略图（缓存）
```

- **切换桌面**：把当前桌面的窗口 `ShowWindow(SW_HIDE)`，把目标桌面的窗口恢复并重排；
- 被隐藏的窗口不出现在系统 Alt+Tab / 任务栏里（这正是替代虚拟桌面的效果）；
- `Ctrl+Alt+Tab` / `Alt+Tab` 在当前桌面的队列内循环；跨桌面切换用 `Ctrl+Alt+↑/↓` 或总览里点选；
- 桌面数量、每个桌面的布局与比例持久化到 `settings.json`；
- 重启后按"进程 + 标题"尽量把窗口恢复到原桌面，认不出的窗口落到当前桌面。

## 必须解决的安全问题

1. **崩溃恢复**：隐藏窗口如果进程异常退出，窗口会一直隐藏。启动时检测上次异常退出 → 恢复所有隐藏窗口；再提供一个"全部唤回"热键；
2. **兼容性**：少数应用被 `SW_HIDE` 后会停止刷新/丢焦点，恢复时需要用 `ShowWindow(SW_SHOWNA)` + 重排；
3. **提权窗口**：仍受 UIPI 限制，需要管理员身份运行（与现有机制一致）；
4. **总览性能**：缩略图优先用 DWM 缩略图，未激活桌面的窗口直接画缓存截图，避免每帧合成。

## L1 / L2 的取舍

- L1 只装在工作区开启期间，钩子超时风险可控（处理逻辑只做"标记 + 之后异步切换"）；
- L2 的 Win+Tab 接管建议与 L1 同时提供，但默认关闭；一旦接管，必须在总览里保留"退出工作区"的入口，避免用户被困。

## 与其它规划的关系

- v0.3 工作区条是 L1 的视觉载体；
- v0.4 的任务视图 = L2；
- v0.6 的虚拟桌面 = L3，依赖 L2 的总览 UI；
- 滚动工作区（v0.5）是同一套槽位模型的"视口偏移"，与桌面切换正交，可叠加。
