# 布局卡片设置

## 交互

- **卡片主体单击**：立即按该布局排布（保持现状，不进设置）；
- **卡片右上角齿轮**：打开该布局的设置弹窗；弹窗内的操作不触发排布（齿轮单独吃掉点击事件）；
- 弹窗底部：`恢复默认` / `取消` / `保存`；保存即写入 `settings.json`，下次排布生效；
- 齿轮平时淡显，鼠标悬停卡片时变明显。

## 参数

| 布局 | 参数 | 默认 |
|---|---|---|
| 层叠（Cascade） | 最多窗口数 | 8 |
| | 错开步长 | 30px |
| | 窗口占工作区比例 | 75% |
| 左右并排（Columns） | 最多列数 | 0 = 不限（自动分行） |
| | 窗口间距 | 沿用全局 |
| 上下堆叠（Rows） | 列数 | 2（固定） |
| | 左列宽度比例 | 55% |
| | 每列最多窗口数 | 0 = 不限 |
| 网格（Grid） | 最大列数 | 4 |
| 主窗在左（MainLeft） | 最多窗口数 | 3 |
| | 主窗宽度比例 | 55% |

## 超限窗口

超过"最多窗口数"的窗口**不参与排布，保持原位**，状态栏提示「已排列 N 个，M 个未参与」。
（备选：最小化 / 层叠到角落，后续如需要可做成卡片设置里的选项。）

## 取哪 N 个

前台窗口优先，其余按 Z 序从前往后取。
与"主窗在左"选择主窗的逻辑一致。

## 持久化

```json
{
  "layoutLimits": { "Cascade": 8, "MainLeft": 3, "Columns": 0, "Rows": 0, "Grid": 4 },
  "layoutOptions": {
    "Cascade": { "Step": 30, "Scale": 0.75 },
    "MainLeft": { "MainRatio": 0.55 }
  }
}
```

## 验收

1. 单击卡片仍然立即排布，不弹窗；
2. 点齿轮只弹设置，不排布；
3. 层叠设为 8 后，超过 8 个窗口时只排前 8 个，其余不动，状态栏有提示；
4. 主窗在左设为 3 后，只有 1 主 + 2 右侧参与，其余不动；
5. 保存后重启程序设置仍在；「恢复默认」能还原。

## 与其他布局的关系

- 设置只影响该布局的"一次性排布"；
- 分区工作区（v0.2）使用独立参数（见 `docs/ZONES.md`），不读取这里的上限。
