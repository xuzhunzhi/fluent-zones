# 首次使用引导（规划）

> 目标：第一次启动时用一页式引导把关键偏好问完，之后不再打扰；所有选项都能在设置里改。

## 触发

- `settings.json` 里 `OnboardingCompleted = false` 时，主窗口首次显示后弹出；
- 可选择「稍后设置」，不阻塞使用（沿用默认值）；
- 设置页提供「重新查看引导」。

## 步骤（单窗口向导，可跳过）

| 步骤 | 内容 | 写入偏好 |
|---|---|---|
| 1. 欢迎 | 一句话定位：Fluent 风格的窗口分区工具；`Ctrl+Alt+Z` 进入分区模式 | — |
| 2. 槽位策略 | 动态分配（默认）/ 固定 N 格 / 每次询问，配一句各自的行为说明 | `ZoneSlotPolicy` |
| 3. 默认布局 | 进入工作区时默认用哪种布局（左右并排 / 网格 / 主窗在左…） | `ZoneDefaultLayout` |
| 4. 热键确认 | 展示默认热键表，冲突项标红并就地改键 | `Hotkeys` |
| 5. 权限说明 | 管理员程序的窗口需要以管理员身份运行；提供「以管理员身份重启」按钮 | — |
| 6. 完成 | 提示 `Ctrl+Alt+Z`，可选「开机启动」 | `StartWithWindows` |

## 原则

- 任何一步都能跳过，跳过即用默认值；
- 不重复打扰：完成后不再弹出，除非用户主动"重新查看"；
- 与帮助文档同源：每步的说明文字与 `docs/ZONES.md` 保持一致，避免两套说法。

## 版本安排

- **v0.2**：不做引导。槽位策略未设置时按默认「动态分配」，设置页可改；
- **v0.3**：实现引导页（与工作区条同版），首次启动走一遍；
- 引导页做成独立 WinUI 页面，便于以后加"迁移旧配置""导入布局"等步骤。
