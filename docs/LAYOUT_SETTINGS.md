# 布局卡片设置

## 交互

- **卡片主体单击**：立即按该布局排布（保持现状，不进设置）；
- **卡片右上角齿轮**：打开该布局的设置弹窗；弹窗内的操作不触发排布（齿轮单独吃掉点击事件）；
- 弹窗底部：`恢复默认` / `取消` / `保存`；保存即写入 `settings.json`，下次排布生效；`恢复默认` 只把弹窗里的值改回默认，点保存才写入；
- 齿轮平时淡显，鼠标悬停卡片时变明显；
- 目前网格（`最多窗口数` 2–6）和左右并排（`每行列数` 3–4）有可调参数，其余三张卡片的齿轮置灰不可点。

## 参数

| 布局 | 参数 | 默认 |
|---|---|---|
| 层叠（Cascade） | 最多窗口数 | 8 |
| | 错开步长 | 30px |
| | 窗口占工作区比例 | 75% |
| 左右并排（Columns） | 每行列数 | 4（范围 3–4，齿轮弹窗用下拉选） |
| | 窗口间距 | 沿用全局 |
| 上下堆叠（Rows） | 列数 | 2（固定） |
| | 左列宽度比例 | 55% |
| | 每列最多窗口数 | 0 = 不限 |
| 网格（Grid） | 最多窗口数 | 4（范围 2–6，齿轮弹窗可调） |
| | 主窗占比 | 62% × 62%（暂固定，未做成设置） |
| | 主窗位置 | 左上（暂固定，未做成设置） |
| 主窗在左（MainLeft） | 最多窗口数 | 3 |
| | 主窗宽度比例 | 55% |

## 超限窗口

超过"最多窗口数"的窗口**直接最小化**（按 Z 序，最久没用的先下去），状态栏提示「已排列 N 个窗口，最小化 M 个最久未使用的窗口」。
`Ctrl+Alt+0` 还原时会把它们一起放回去。

## 最小尺寸放不下

整组窗口按声明的最小尺寸排不下时：**网格**先询问——单个窗口装不下就建议「放到主窗」，多个都装不下就弹「最小化 N 个后重排 / 改用层叠 / 取消」；**其它布局**按 Z 序**从最底层开始少排几个**，前台窗口优先进入布局，放不下的窗口**保持原位**（状态栏写「N 个窗口放不下，保持原位」），不会直接弹「放不下」。
只有连单个前台窗口都排不下时才会提示「窗口最小尺寸放不下，可以改用层叠」。

## 取哪 N 个

前台窗口优先，其余按 Z 序从前往后取。
与"主窗在左"选择主窗的逻辑一致。

## 持久化

```json
{
  "LayoutLimits": { "Grid": 4, "Columns": 4 }
}
```

键是 `LayoutKind` 的名字；缺失时按默认值（Grid 4 / Columns 4）。目前 `Grid`（最多窗口数）和 `Columns`（每行列数）会读这个值，其余布局的参数（层叠 8 / 主窗在左 3 / 列数 / 步长 / 比例）还没实现。

## 验收

现状（网格 + 左右并排）：

1. 单击卡片仍然立即排布，不弹窗；
2. 点网格齿轮只弹「网格平铺设置」、点左右并排齿轮只弹「左右并排设置」，都不触发排布；其余三张卡片的齿轮置灰不可点；
3. 网格设成 4 后，7 个窗口只排前 4 个，其余 3 个被最小化，状态栏有提示；
4. 左右并排选 3 列后，超过 3 个窗口自动换行（每行最多 3 个）；
5. 弹窗里「恢复默认」把值改回默认，点「保存」才写入；保存后重启程序设置仍在；
6. 待做：层叠 / 主窗在左 / 上下堆叠 的参数。

## 与其他布局的关系

- 左右并排的「每行列数」同时用于一次性排布和分区工作区（同一份换行几何）；其余设置只影响该布局的一次性排布；
- 分区工作区（v0.2）的其余参数见 `docs/ZONES.md`。
